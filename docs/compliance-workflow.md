# Compliance Workflow

A compliance automation system should preserve the full record of conditions, actions, evidence, reviews, approvals, and submissions.

## Workflow Stages

1. Permit or requirement registered
2. Responsible party assigned
3. Evidence requirement defined
4. Inspection or monitoring record attached
5. Internal review completed
6. Exception or deficiency identified
7. Corrective action recorded
8. Approval completed
9. Submission package prepared
10. Final record archived

## Data Objects

- Permit
- Condition
- Evidence record
- Inspection record
- Review comment
- Approval event
- Submission package
- Audit event

## Design Principle

Compliance systems should support accountability and documentation. They should not claim automatic legal compliance.
